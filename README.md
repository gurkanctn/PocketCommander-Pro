# Pocket Commander Pro

A tactical RTS tower-defense game — command your army, build defenses, and
survive endless waves on a 40×40 grid. Playable on desktop and mobile
(touch, pinch-zoom, drag-scroll). Offline-capable PWA.

## Play

Open the deployed site, or download this folder and open `index.html` in any
modern browser. No build step, no dependencies.

## Version

0.1.0029

## Features

- Single-file app (HTML/CSS/JS in one `index.html`, canvas-rendered)
- Built-in tile-based level editor
- Local saves via localStorage
- 4 biomes (grass, desert, snow, swamp), a different boss per biome every 10 waves
- Eight enemy variants: swarmers, brutes, spitters, armoured, bombers, healers, splitters, flyers
- Web Audio synthesized sound effects and generative per-biome ambient music
- Build-break wave calling, ×1–×3 speed, per-map records and a daily streak
- Pause / save & resume, settings (volume, UI size, colour-blind, high contrast), first-run tutorial
- Balance tuned with headless scripted players
- Per-tower upgrade tracks (fire rate / power / health) and a grouped TOWERS build menu with NEW highlights
- Builder variants (Hauler, Engineer) and soldier variants (Rifleman, Guardian, Grenadier) unlocked by research
- Barracks recruits with randomly rolled stats and quality tiers that scale with Barracks tech
- Research Lab with a tech tree: new towers stay hidden until researched
- Builders construct every building (more builders build faster; cancel a site for a full refund)
- Attack styles: laser beams, projectiles, lobbed shells, zone blasts, pulses and acid pools
- PWA: installable, offline-capable, update prompt
